# Hotel Nocturne audio assets

All files in this directory are original procedural assets generated specifically for this repository. No third-party audio samples are used.

Planned files:
- `rain-loop.wav` — low-volume rain ambience loop
- `hotel-hum-loop.wav` — interior electrical/HVAC ambience loop
- `thunder.wav` — distant thunder one-shot
- `card-click.wav` — short keycard/lock click
- `evidence-sting.wav` — positive evidence discovery sting
- `contradiction-sting.wav` — tense contradiction sting

Playback is handled by Phaser Sound. The game exposes a persisted Sound on/off setting independently from detective TTS.
