# Roosevelt visual QA gate

The generated mockup is the visual target for the current pass.

Before moving on to unrelated features, each major art change is validated on the public Vercel preview at 1280x720 for lobby, Floor 3 / Room 307 and basement.

Current acceptance focus:
- hotel fills most of the game viewport;
- visible room footprints are broader than the navigation-only Walkable mask;
- full-height cutaway walls read as architecture rather than low borders;
- Room 307, elevator, reception, CCTV and laundry are recognizable from the art itself;
- characters remain readable at default zoom;
- free pan/zoom remains usable.
