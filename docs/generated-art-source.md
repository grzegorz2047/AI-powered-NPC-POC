# Generated art source sheets

The Roosevelt visual pass uses original visual material created specifically for this project and supplied as the approved #14 baseline:

- `noir_hotel_isometric_tileset.png` — isolated hotel architectural modules and props;
- `izometryczna_linia_hotelowych_postaci_noir.png` — isolated detective and hotel witness character lineup;
- the approved Hotel Nocturne Floor 3 mockup — the hard visual QA reference for Room 307 composition, materials, lighting and HUD proportions.

Prepared runtime crops are derived only from those project-owned/supplied source sheets. `mockup-room307-reference-plate.svg` contains a compressed crop of the approved Room 307 mockup so the benchmark room keeps the same wall material, bed, lighting, window, TV and lounge composition while real Tiled navigation and interactions remain separate Phaser objects.

The target is a mockup-guided noir isometric CRPG look. No Fallout artwork, UI asset, texture or character art is copied into the project.
